# InAmigos Foundation NGO Awareness Website

A modern and responsive NGO awareness website developed for **InAmigos Foundation** using **HTML, CSS, and JavaScript**.

This project was designed to spread awareness about the foundation’s social initiatives, community programs, and impact-driven activities through a clean and professional user interface.

---

## 🌟 Features

* Responsive modern UI design
* Professional NGO landing page layout
* Smooth scrolling and reveal animations
* Social impact statistics section
* Community project showcase
* Real NGO gallery images
* Call-to-action sections
* Mobile-friendly design
* Clean and structured codebase

---

## 📌 NGO Initiatives Highlighted

* Project SEVA
* Project BACHPANSHALA
* Project JEEV
* Project UDAAN
* Project PRAKRITI
* Project VIKAS

## 🎯 Project Objective

The purpose of this project is to create an impactful digital platform that highlights the mission, projects, and community contributions of InAmigos Foundation while maintaining authenticity and professional presentation.
